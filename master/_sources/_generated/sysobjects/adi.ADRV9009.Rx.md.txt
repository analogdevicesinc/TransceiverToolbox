<div class="sysobj_desc_title">Example Usage</div>

```matlab

%% Rx set up
rx = adi.ADRV9009.Rx('uri','ip:analog.local');

rx.CenterFrequency = 1e9;

rx.EnabledChannels = 1;
%% Run
for k=1:10
    valid = false;
    while ~valid
        [out, valid] = rx();
    end
end

```
